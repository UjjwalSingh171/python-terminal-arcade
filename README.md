# Python Terminal Arcade

A small terminal arcade written in Python. It currently includes:

- Rock Paper Scissors
- Guess My Number

## Requirements

- Python 3.8 or newer
- No third-party packages

## Run the arcade

Clone the repository and open its folder:

```bash
git clone https://github.com/UjjwalSingh171/python-terminal-arcade.git
cd python-terminal-arcade
```

Start the arcade with your name:

```bash
python3 arcade.py --name Ujjwal
```

On Windows, use `python` instead of `python3` if needed:

```bash
python arcade.py --name Ujjwal
```

You can also run either game separately:

```bash
python3 rps.py --name Ujjwal
python3 guess_number.py --name Ujjwal
```
